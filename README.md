# PicFix Android Prototype

PicFix combines an AI Photo Studio with a Local Services marketplace.

## Included
- Home dashboard
- Men / Women / Couple / Wedding photo categories
- Wedding template flow
- Android gallery photo picker
- Photo preview/edit-flow screen
- Local services categories
- Provider details
- Booking flow
- My Bookings screen

## Important
This is a functional UI prototype. The actual AI image generation, payments, maps, authentication, provider database, notifications, and production booking backend still need to be connected to real services/APIs.

## Open
Open this folder in Android Studio and let Gradle sync. Then run on an Android device/emulator.
